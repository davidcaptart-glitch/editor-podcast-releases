# Política de privacidad — Editor Podcast

*Última actualización: 20 de octubre de 2026*

Editor Podcast es un programa de escritorio para Windows que edita vídeos de
podcast en el ordenador de quien lo usa. Esta página explica qué datos trata.

## Qué datos usa
- **Tus vídeos y audios** se procesan **solo en tu ordenador**. El programa no los
  envía a ningún servidor propio: no tenemos servidores.
- **YouTube (opcional).** Si conectas tu cuenta para subir un episodio, el programa
  usa la API de datos de YouTube de Google con los permisos que tú das en la
  pantalla de Google: subir vídeos y gestionar sus subtítulos. El vídeo, el título,
  la descripción, las etiquetas y los subtítulos van **directamente de tu ordenador
  a tu canal**. El permiso (token) se guarda solo en tu ordenador
  (`%APPDATA%\EditorPodcast`) y puedes borrarlo con «Desconectar» o retirarlo en
  https://myaccount.google.com/permissions.
- **Claude (opcional).** Si activas el asistente con Claude, se envía a Anthropic
  únicamente el texto de la transcripción del episodio para proponer título,
  descripción y capítulos. La clave se guarda solo en tu ordenador.
- **Actualizaciones.** El programa consulta este repositorio de GitHub para saber
  si hay una versión nueva.

## Qué no hace
- No recoge estadísticas de uso ni datos personales.
- No vende ni comparte datos con terceros.
- No usa los datos de Google para nada distinto de lo que tú pides (subir tu
  vídeo). El uso de la información recibida de las API de Google cumple la
  [Política de datos de usuario de los servicios de API de Google](https://developers.google.com/terms/api-services-user-data-policy),
  incluidos los requisitos de uso limitado.

El uso de YouTube está sujeto a las
[Condiciones del servicio de YouTube](https://www.youtube.com/t/terms) y a la
[Política de privacidad de Google](https://policies.google.com/privacy).
